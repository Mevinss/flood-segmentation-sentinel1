# Курстық жұмысты көрсету және дайын модельді қолдану

Дайын оқытылған модель `models/attention_unet_resnet34.joblib` файлына енгізілді. Көлемі — 91,5 МБ. Бастапқы checkpoint пен қайта жүктелген модельдің барлық салмақтары және Bolivia_103757 суретіндегі ықтималдықтары дәл сәйкес келеді. Тексеру нәтижесі `outputs/checkpoint_export_verification.json` ішінде сақталған.

Негізгі файл — **FloodSegmentation_KZ.ipynb**. Ноутбуктың барлық түсіндірмесі қазақ тілінде. Модель — Attention U-Net, энкодері ResNet-34. Деректер — Sen1Floods11 v1.1, Sentinel-1 VV/VH, dB.

## Бумалар

- `FloodSegmentation_KZ.ipynb` — құрылымды жұмыс, оқыту коды, графиктер, болжам және joblib экспорты.
- `models/attention_unet_resnet34.joblib` — оқытылған модель салмақтары және оны қолдануға қажет параметрлер.
- `inference.py` — ноутбуктен тәуелсіз модельді жүктеу және суретке болжау жасау коды.
- `data/splits/` — барлық 446 фрагменттің ресми train/validation/test/Bolivia тізімдері.
- `data/S1Hand/`, `data/LabelHand/` — демонстрацияның екі Боливия суреті. Олар репозиторийге қосылмаған; `python download_demo_data.py` командасы немесе ноутбуктың өзі оларды ресми Sen1Floods11 көзінен жүктейді.
- `download_demo_data.py` — демонстрация суреттерін жүктеу.
- `reports/` — бастапқы оқыту тарихы, валидациялық шектер және сақталған тест нәтижелері.
- `outputs/` — осы іске қосуда жасалған графиктер, маскалар, метрикалар және қайта экспортталған модель.

## Дайын салмақты орналастыру

Егер models бумасында joblib файлы болмаса, толық жүктелген best.pt файлын осы README тұрған бумаға сақтаңыз. Ноутбук оны бірінші жүктеу кезінде joblib форматына автоматты түрлендіреді. best.pt Google Drive-та attention_resnet34_seed42 бумасындағы 34-дәуірдің үздік checkpoint файлы болуы керек.

Жеке экспорт командасы да қолжетімді.

    python export_checkpoint.py best.pt

## Jupyter-де ашу

Python 3.11 ұсынылады. Терминалды осы бумада ашып орындаңыз.

```bash
python -m pip install -r requirements.txt
python download_demo_data.py
python -m jupyter lab FloodSegmentation_KZ.ipynb
```

Жоба тұрған компьютерде дайын орта да бар. Курстық жұмыстың негізгі бумасынан орындауға болады.

```powershell
& .\flood_project\.venv\Scripts\python.exe -m jupyter lab .\FloodSegmentation_Defense\FloodSegmentation_KZ.ipynb
```

Ноутбукте `Kernel → Restart Kernel and Run All Cells` таңдаңыз. Әдепкі режим CPU-да екі Боливия суретіне болжам жасайды, графиктерді көрсетеді және соңында joblib экспортын тексереді. Метрикалары бар 90 суреттік негізгі тест кестесі сақталған бастапқы нәтижеден оқылады. Демонстрацияның екі суреттік метрикалары орындау кезінде қайта есептеледі.

## Толық тәжірибені қайталау

Алғашқы код ұяшығындағы параметрлер қолданылады.

| Параметр | Орындалатын әрекет |
|---|---|
| `RUN_FULL_DATA=True` | Толық 446 фрагментті жүктеу, аудит және train нормализациясын есептеу |
| `RUN_TRAINING=True` | Толық деректерді дайындау және жаңа GPU оқытуын `outputs/retraining` ішіне сақтау |
| `RUN_FULL_TEST=True` | Дайын модельді 90 test және 15 Bolivia суретінде қайта бағалау |

Қайта оқытуға Colab GPU таңдаңыз. Colab-та дайын архивті `/content` бумасына ашып, `%cd /content/FloodSegmentation_Defense` орындаңыз. Ортадағы torch/torchvision жұбын сақтап, requirements ішіндегі қалған пакеттерді орнатуға болады. Негізгі қажет архитектура кітапханасы — `segmentation-models-pytorch==0.5.0`.

Жаңа оқыту жеке тәжірибе ретінде сақталады. Осы есептің нәтижелері бастапқы 34-дәуірдегі модельге тиесілі. Жаңа модель үшін валидациялық шек пен тест нәтижелері бөлек есептелуі керек.

## Joblib файлын қолдану

Joblib файлында `state_dict` NumPy массивтері, конфигурация, нормализация, 0,473 шегі, 34-дәуір белгісі, ресми split идентификаторлары және бастапқы checkpoint хэші бар. Архитектураны `inference.py` құрады. Осы файл мен тәуелділіктерді модельмен бірге беріңіз. Joblib файлын сенімді көзден ғана жүктеңіз.

```python
from inference import load_export, predict_file

model, metadata, device = load_export(
    'models/attention_unet_resnet34.joblib', device='cpu'
)
probability, water, valid = predict_file(
    'models/attention_unet_resnet34.joblib',
    'data/S1Hand/Bolivia_103757_S1Hand.tif',
    'outputs/prediction.tif',
)
```

Немесе терминалдан орындаңыз.

```bash
python inference.py --model models/attention_unet_resnet34.joblib --image data/S1Hand/Bolivia_103757_S1Hand.tif --output outputs/prediction.tif
```

Кіріс — екі арналы 512×512 Sentinel-1 GeoTIFF, арна реті VV/VH және бірлігі dB. Шығыс растрда 0 — құрлық, 1 — су, 255 — жарамсыз пиксель. CRS пен геотрансформация сақталады.

## Деректер және нәтижені түсіндіру

Ресми деректер көзі — https://github.com/cloudtostreet/Sen1Floods11. Бұл жинақтағы су маскасына тұрақты су да кіреді. Жаңадан су басқан аумақты дәл бөліп алу үшін тасқынға дейінгі жағдай немесе тұрақты су картасы қажет.

Сақталған негізгі тест нәтижесі — IoU 0,6886177462, Dice/F1 0,8155993241, Precision 0,8183625751, Recall 0,8128546708. Бұл мәндер 90 фрагменттің жарамды пиксельдері бойынша есептелген. Боливия бөлек 15 фрагменттік географиялық тексеру болып табылады.

Кодты реттеу мен экспорттауда OpenAI Codex қолданылды. Архитектура мен тәжірибе нәтижелері бастапқы жоба материалдарына негізделген. Комиссия алдында студент модельдің құрылысын, деректер бөлінуін және метрикалардың мағынасын түсіндіреді.
